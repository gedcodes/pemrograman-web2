    Aturan Keamanan

    verified_user§5.4
    • Server Key tidak pernah masuk repositori. Payment Link tidak butuh Server Key sama sekali.
    • Hanya kredensial Sandbox. URL production ditolak oleh validasi.
    • URL disimpan di pengaturan terpisah, bukan di logika kasir.
    • Data kartu tidak pernah disimpan aplikasi; semua input sensitif di halaman Midtrans.

    Alur Konfirmasi

    1. Kasir memilih Non-Tunai, pelanggan memindai QR.
    2. Pelanggan mengisi nominal sesuai total dan membayar.
    3. Kasir memeriksa status di Midtrans lalu menekan Konfirmasi Lunas, atau menyimpan sebagai Pending.
    4. Transaksi pending diverifikasi kemudian di Riwayat Transaksi.
